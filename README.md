# CodeAlpha_BankingSystem

A C++ Object-Oriented Banking System that supports deposits, withdrawals, fund transfers, and transaction history tracking.

## 🚀 Features

- **Account Information Management:** Display detailed account information along with associated customer details.
- **Deposit & Withdrawal:** Securely add or withdraw funds with validation for invalid amounts and insufficient balance.
- **Fund Transfer:** Transfer money directly between two accounts with real-time balance updates for both parties.
- **Transaction History:** Log every transaction with unique IDs and view recent transactions on demand.
- **Interactive Menu:** Console-based interface for seamlessly performing financial operations.

---

## 🛠️ Tech Stack & OOP Concepts Used

- **Language:** C++
- **Key Concepts:**
  - Object-Oriented Programming (Classes, Objects, Constructors)
  - Member Functions & Encapsulation
  - Standard Template Library (`std::vector`, `std::string`)
  - Static Class Members (Auto-incrementing Transaction IDs)
